# digi-dino-restoration-study
Modernizing Digi Dino, an open-source virtual pet app, for compatibility with modern Android devices. Exploring legacy code, updating the build environment, and documenting the modernization process.

Digi Dino — Technical Restoration Study

About this project

This repository documents a learning project focused on the technical restoration and modernization of an older Android application.

Original project: "Digi Dino by Amy Hart and the original contributors" (https://github.com/amy-hart/digi-dino)

The goal was to explore whether the existing application could be brought onto a more modern React Native and Android build toolchain, while preserving the original game's content and functionality.

Scope

The work focused on the application's technical foundation rather than redesigning the game itself, including:

- Investigating the existing project structure and build configuration
- Exploring a modern React Native and Android SDK setup
- Working with Gradle and Android build tooling
- Producing and testing a functioning application build

The modernization process was carried out primarily with assistance from ChatGPT.

Learning goals

This project helped explore the challenges of maintaining older mobile applications, including dependency compatibility, Android SDK levels, React Native upgrades, and modern build tooling.

The purpose is to document the restoration process transparently and to identify the technical decisions, limitations, and lessons learned.
